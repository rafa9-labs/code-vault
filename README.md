# Code Vault

Code Vault is a VS Code developer utility for keeping commands, snippets, functions, and notes close to the editor.

## Features

- Activity-bar tree view for organised developer knowledge
- Fuzzy search across saved items
- Quick copy and optional command execution
- JSON import and export for backups and sharing
- Local persistence through VS Code global state

## Development

```bash
npm install
npm run compile
npm run package
```

## Stack

TypeScript · VS Code API · Webpack · Node.js
