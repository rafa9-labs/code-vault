# Change Log

## [1.0.0] — 2026-03-28

### Added
- Sidebar tree view with categories: Commands, Snippets, Functions, Notes
- Add, edit, and delete items with a rich webview editor
- Copy item content to clipboard
- Execute command items in the terminal
- Fuzzy search across all items
- Export data to versioned JSON
- Import data (merge or replace)
- Keyboard shortcuts for common actions
- Configurable settings (terminal profile, delete confirmation, language badges)
- Alphabetical sorting within categories
- Language badges for snippets and functions
- Rich markdown tooltips with content preview
